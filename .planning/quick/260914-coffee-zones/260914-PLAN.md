# Coffee zones and map clustering

## Goal

Add curated, soft-radius coffee zones and zoom-aware dynamic map clusters while preserving the legacy `GET /api/Map` response when `zoom` is omitted.

## Tasks

1. Add the CoffeeZone aggregate, membership overrides, EF mappings, and migration.
2. Add moderator CRUD, publication, membership preview/override, and DBSCAN candidate APIs.
3. Extend the public map query with optional zoom, stable clustering, published zone cards, primary-zone resolution, and truncation metadata.
4. Add domain/application tests and run the Shops-focused and full CI test suites.

## Constraints

- Keep all existing public fields and legacy no-zoom behavior.
- Use decimal coordinates and Haversine calculations; do not introduce PostGIS.
- Do not persist generated candidates or automatically reshape published zones.
