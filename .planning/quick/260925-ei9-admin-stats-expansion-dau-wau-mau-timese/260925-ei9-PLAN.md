## Decided API shape (implement exactly)

Contract DTOs (namespace CoffeePeek.Contract.Dtos.Admin, positional records, collections as IReadOnlyList<T>):
- AdminOverviewStatsDto: append AFTER `bool ModerationAvailable = true` the defaulted params `int DailyActiveUsers = 0, int WeeklyActiveUsers = 0, int MonthlyActiveUsers = 0, int DeletedUsers = 0, int EmailConfirmedUsers = 0, int GoogleUsers = 0` (non-breaking).
- AdminTimeseriesDtos.cs: `AdminDailyCountDto(DateOnly Date, int Count)`; `AdminUsersTimeseriesDto(int Days, IReadOnlyList<AdminDailyCountDto> NewUsers)`; `AdminShopsTimeseriesDto(int Days, IReadOnlyList<AdminDailyCountDto> NewShops, IReadOnlyList<AdminDailyCountDto> NewReviews, IReadOnlyList<AdminDailyCountDto> NewCheckIns)`.
- AdminShopsInsightsDto.cs: `AdminShopsInsightsDto(AdminRatingStatsDto Ratings, IReadOnlyList<AdminTopShopDto> TopShopsByCheckIns30Days, IReadOnlyList<AdminTopShopDto> TopShopsByReviews, AdminAppDownloadStatsDto Downloads)`; `AdminRatingStatsDto(int TotalReviews, decimal AverageRating, decimal AveragePlace, decimal AverageService, decimal AverageCoffee, IReadOnlyList<AdminRatingBucketDto> Distribution)`; `AdminRatingBucketDto(int Stars, int Count)`; `AdminTopShopDto(Guid ShopId, string Name, int Count)`; `AdminAppDownloadStatsDto(int Total, int Last30Days, IReadOnlyList<AdminDownloadChannelDto> ByChannel, IReadOnlyList<AdminDownloadCountryDto> TopCountries30Days)`; `AdminDownloadChannelDto(string Channel, int Total, int Last30Days)`; `AdminDownloadCountryDto(string Country, int Count)`.
- AdminModerationInsightsDto.cs: `AdminModerationInsightsDto(AdminModerationSlaDto Sla, IReadOnlyList<AdminModerationQueueDto> Queues, double? OldestPendingHours, IReadOnlyList<AdminModeratorWorkloadDto> TopModerators30Days)`; `AdminModerationSlaDto(int ReviewsModerated30Days, double? AvgReviewModerationHours)`; `AdminModerationQueueDto(string Queue, int Pending, double? OldestPendingHours)`; `AdminModeratorWorkloadDto(Guid ModeratorUserId, int Total, int Approved, int Rejected)`.

Endpoints (all GET, all `[Authorize(Policy = RoleConsts.Admin)]` via the existing AdminStatsController classes, route prefix `api/admin/stats`):
- Account `overview` (extended) and `users/timeseries?days=30` -> Response<AdminUsersTimeseriesDto>
- Shops `shops/insights` -> Response<AdminShopsInsightsDto>; `shops/timeseries?days=30` -> Response<AdminShopsTimeseriesDto>
- Moderation `moderation/insights` -> Response<AdminModerationInsightsDto>

Shared semantics: "today" = DateTime.UtcNow.Date; timeseries window = days `today-(days-1)` .. `today` inclusive, days clamped to 1..90 (default 30) in the handler; "last 30 days" windows = `DateTime.UtcNow.AddDays(-30)` (rolling). Hours values rounded to 1 decimal; averages to 2 decimals (MidpointRounding.AwayFromZero).
