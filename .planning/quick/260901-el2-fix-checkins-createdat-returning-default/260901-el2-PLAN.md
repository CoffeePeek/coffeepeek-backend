<objective>
Fix `GET /api/CheckIns` returning `createdAt: "0001-01-01T00:00:00"` instead of the check-in's
real timestamp. `CheckInDto.CreatedAt` (`CoffeePeek.Contract/Dtos/CoffeeShop/CheckInDto.cs`) has no
same-named counterpart on the `CheckIn` domain entity — the entity only exposes `CreatedAtUtc`
(inherited from `CoffeePeek.Shared.Domain.Entities.Entity<TId>`). Mapster only matches properties
by exact name, and the existing `config.NewConfig<CheckIn, CheckInDto>()` in
`CoffeePeek.Shops.Application/Mapper/MapsterConfiguration.cs` only does
`.Ignore(dest => dest.ShopName)` — it never maps `CreatedAt`, so `ProjectToType<CheckInDto>` (used
by `CheckInQueries.GetByUserId`) leaves it at `default(DateTime)`.

Output: `CreatedAt` is explicitly mapped from `CreatedAtUtc` in that Mapster config. A regression
test adapts a real `CheckIn` entity (via its existing `CheckIn.Create(...)` factory, which sets
`CreatedAtUtc = DateTime.UtcNow`) through the actual `MapsterConfiguration` and asserts
`CheckInDto.CreatedAt` equals the entity's `CreatedAtUtc`.
</objective>
