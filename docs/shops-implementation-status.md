# ShopsService: журнал реализации архитектурного плана

Дата обновления: 9 октября 2026 года. Этот журнал показывает состояние кода и проверок относительно [P01–P35](shops-modularization-plan.md). «Реализовано в коде» не означает прохождение PostgreSQL, RabbitMQ, Redis и полного выпускного контура.

Срез P28 зон подтверждён [CI commit caeb60f2](https://github.com/CoffeePeek/coffeepeek-backend/actions/runs/37894472606): десять сценариев успешного commit и rollback после SQL-readback прошли на PostgreSQL 17. Команды, handlers и DTO зон разделены по правилу одного top-level типа на файл. Следующий срез переводит PUT/DELETE избранного и отчёт об ошибке импорта в Wolverine-команды; три HTTP→store исключения удалены, осталось восемь. HTTP/auth regression проходит локально; все шесть новых live-сценариев commit/rollback прошли обязательный PostgreSQL 17 gate в [CI commit 6f8f5f42](https://github.com/CoffeePeek/coffeepeek-backend/actions/runs/37896146032). Исторические отметки «ожидает CI» в таблице ниже относятся к моменту реализации: существующие PostgreSQL-классы уже прошли run `37894472606`; это не закрывает физические broker/cache faults и проверку старой БД.

Следующий срез P25/P28 убрал все восемь оставшихся HTTP→store записей. `HostWriteBypassTests` теперь требует пустой список без baseline исключений. Семь новых commands и generated adapters, 15 HTTP/controller проверок и 17 PostgreSQL-сценариев добавлены; локальный regression прошёл, новый live gate требует CI. Остались межмодульные записи, CoffeeCatalog lifecycle и выпускные проверки.

Локальный SDK работает, Docker CLI установлен, но PostgreSQL и Docker engine на этом Windows-хосте не запущены. Поэтому `LivePostgres` здесь честно сообщает `Skipped`; CI запускает PostgreSQL-классы с отказом при нуле тестов или пропусках. Полные Release `dotnet build` и `dotnet test CoffeePeek.Backend.ci.slnf --no-build` проходят: 2019 пройдено, 118 пропущено, 0 упало. Из 118 пропусков 106 относятся к Shops Infrastructure live PostgreSQL, 9 — Account Infrastructure, 3 — legacy migration. Release build завершился без ошибок, но содержит ранее существовавшие предупреждения CS1591/xUnit1051/nullable; предупреждения не закрыты в этой работе. NuGet vulnerability audit прошёл CI `caeb60f2`. Эти результаты не заменяют физические RabbitMQ/Redis/Media fault tests и миграционный прогон старой БД.
