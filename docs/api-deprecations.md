# API deprecations

## API-001

**Открытая задача: удалить `GET /api/CoffeeShops` после перехода выбора кофейни для чекина на v1.**

- Статус: ожидает миграции мобильного выбора кофейни; не завершена объявлением deprecated.
- Дата объявления: 2026-10-26.
- Замена: `POST /api/v1/coffee-shops/search`.
- Область: мобильный выбор кофейни для чекина и backend Shops/Gateway.
- Дата отключения не назначена: endpoint нужен поддерживаемым клиентам.

### Текущий временный контракт

`GET /api/CoffeeShops?q=кофе&city=minsk&page=1&pageSize=10`

Поддерживаются только `q` (название или адрес, до 100 символов), `city` (публичный slug),
`page` (1–10000, по умолчанию 1) и `pageSize` (1–100, по умолчанию 10).
Другие параметры, включая прежние расширенные фильтры, возвращают `400 INVALID_FILTER`
с перечислением неподдерживаемых ключей. Несуществующий город не игнорируется: возвращается 404.

Сохраняются `Response<PublicCoffeeShopsResponse>`, массив `data.coffeeShops`, публичные адреса,
поля карточки, отметка посещения для авторизованного пользователя, пагинация и заголовки `X-Total-Count`,
`X-Total-Pages`, `X-Current-Page`, `X-Page-Size`. Порядок прежний: заполненность карточки, затем название.
В OpenAPI только операция списка отмечена `deprecated: true`. Ответ action содержит:

```http
Deprecation: @1792972800
Link: </api/v1/coffee-shops/search>; rel="successor-version"
```

## Удалено 2026-10-26

`POST /api/v1/discovery/search`: использование прекращено по подтверждению владельца проекта.
Удалены action, Gateway route, отдельный query adapter, DTO и схемы OpenAPI. Путь возвращает 404.
Поиск по приготовлению и цене напитка доступен в `POST /api/v1/coffee-shops/search` через `filters.menu`.
